# 一覧検索画面の標準パターン

## 1. 標準構成

一覧検索画面は、次の4つの要素を必ず持つ。

1. 検索条件部
2. 一覧部（ページング付き）
3. 件数表示
4. CSVダウンロード

この4要素が欠ける場合は、案件の設計レビューで理由を説明すること。

## 2. ページング

- 1ページあたり50件を既定とする。
- 総件数と現在ページ番号を一覧の上部に表示する。
- ページ番号はサーバー側で確定し、画面側で再計算しない。

## 3. 検索条件

- 必須条件は画面上で明示する（ラベルに「必須」を付ける）。
- 条件の初期値は画面初期化 API が返す。画面側でハードコードしない。
- 検索実行前に単項目チェックを行い、エラー時は検索 API を呼ばない。

## 4. CSVダウンロード

- ダウンロードは検索条件を引き継ぎ、ページングを無視して全件を出力する。
- 文字コードは UTF-8（BOM付き）。ファイル名に日時を含める。

## 5. アンチパターン

- 一覧の全件をフロントエンドに返してブラウザ側でページングする。
- 検索条件をURLに載せず、画面再表示で条件が消える。
