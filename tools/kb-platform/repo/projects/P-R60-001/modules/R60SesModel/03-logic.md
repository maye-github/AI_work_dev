## design_vs_implementation_summary

### matched

- 仕掛表示だけ REG_STS='0' を加え、表示は絞らない（R60Plc の D-PL-07 と対照的）。
- 自動採番の範囲・繰上げ規則。
- REG_STS を必須項目の充足で判定する（ヘッダ 4 項目、明細は子コード等）。
- 削除順と対象テーブル。
- 排他 → イベント参照 → 被参照 → 更新の順序。

### divergent

- 指定ソートで副キーが落ちる（D-SM-07）。
- ページングが OFFSET/FETCH（D-SM-08）。
- 更新系が message_id を返さない（D-SM-23）。
- データ初期化の R60I0022 を API が返さない。

### risky

- 件数 SQL と逆引き条件の文字列連結（D-SM-05）。
- search と download の DEL_FLG 判定差（D-SM-06）。
- 顧客会社コードの直書き（D-SM-12）。
