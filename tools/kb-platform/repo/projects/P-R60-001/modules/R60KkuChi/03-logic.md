## design_vs_implementation_summary

### matched

- 項目 → 管理項目 → 検索画面の連動（パターン表）
- 12 パターンのキー構成と、検索条件の完全一致／前方一致
- 削除含むオフ時の DEL_FLG='0' 付加
- 件数 0／上限超過の扱いと上限値の情報 ID
- 排他の比較条件（更新時刻不一致かつ更新区分オンライン）
- 登録時の DB 存在チェック（半製品・メッセージ ID・仕込記号・受払区分）
- 新規・複製のキー存在チェック（R60W0014）
- 登録 32 列・更新 17 列・削除 17 列の列集合
- 確認・完了メッセージの表示
- ソート列のパターン別適用

### mismatched

- 単項目チェックがサーバーに無い（画面側のみ、D-KK-02）
- 検索 WHERE の値がバインドされていない（D-KK-09）
- page_limit の検証が無い（D-KK-10）
- 未知 mode で成功応答（D-KK-11）

### unimplemented_or_dead

- 被参照チェック関数（D-KK-14）
- Service の getSikKgo（端点なし、D-KK-16）
- 9 個・3,795 行の未使用 component（D-KK-15）
- A/B レポート（不在、D-KK-19）
