### 5.4 組織ユニット検索（イベント No4、r68-r89）

- 入力支援画面（データ ID `SSK_UNIT`、検索条件＝画面.会社）を開く。
- 戻り値があれば組織ユニットに設定し、**部署マスタから正式名称を取得**して名称欄に設定。
- 実装は `getSskUnitNm` で `R60_SSK_M_TBL.SEI_NM` を返す【実測】。
  設計の「部署マスタ.正式名称」との対応は【推測】（SSK_M_TBL が部署マスタ、SEI_NM が正式名称）。

### 5.5 マスタ項目モーダル初期化（イベント No11、r146-r268）

1. `initEdit` で対象社員の行と更新区分・更新時刻・リビジョン・送信ステータス・各コードを取得。
2. **S 会社コード／S 事業場コードのいずれかが空白**なら、部署マスタから S 会社・S 事業場を補完。
3. 経理用会社・経理用事業場・役割・帳票共有グループ・帳票参照・帳票権限・ユーザタイプの
   ドロップダウンを生成（7 リスト）。
4. 経理用事業場は **S 会社／S 事業場の状態で絞り込む**（r192-r208）。
5. **自工・他工判別**（r228-r242）：
   - ログインユーザの所属会社／事業場が **経理用会社／事業場と一致** → 自工
   - または **S 会社／S 事業場と一致** → 自工
   - 上記以外、または S 会社／S 事業場のいずれかが空白 → 他工
6. **ボタン制御**（r244-r267）：権限区分='Y' のとき、
   - 自工更新フラグ='0' かつ 他工更新フラグ='0' → 登録 **非活性**
   - 両方='1' → 登録 **活性**
   - それ以外 → 自工なら活性、他工なら非活性
