## 5. 業務処理説明（【文書】`14_業務処理説明` 318 行）

### 5.1 イベント共通

1. **セッション情報存在チェック**：共通関数。不在ならセッションエラー画面（r13-r16）。
2. **オンライン利用可否フラグチェック**：共通関数。NG ならオンライン制御エラー画面（r18-r20）。

### 5.2 検索（イベント No2 / No3）

1. **単項目チェック**：メーカーコード（半角英数字 5 文字、`R60W0103`）、
   メーカー日本語名（30Byte・禁止文字、`R60W0131`）。エラー時点で中断。
2. **WHERE 生成**：
   - コード：**前方一致**（`MAKER_CD LIKE :MAKER_CD`、値は `code + '%'`）
   - 日本語名：**中間一致**（`MAKER_NM LIKE :MAKER_NM ESCAPE '\'`）
   - 削除含む OFF：`DEL_FLG='0'`
   - 仕掛表示：`REG_STS='0'` を追加
3. **件数取得**：`COUNT(ROWID)`。0 件→`R60W0010`、上限超過→`R60W0005`。
   上限はコード値明細 `000000024`（設計書の例は 3000）。
4. **抽出項目**：`R60_GET_SELECT_COLUMN_FNC('R60_MAKER_M_TBL','L')`（実装は utility 経由）。
5. **ソート順**：`DEL_FLG` 昇順 → `MAKER_CD` 昇順。
   **ユーザー指定ソートは `MAKER_CD` / `MAKER_NM` の 2 つだけ**（実装の白名单）。
6. **ページング**：`OFFSET ... FETCH FIRST ... ROWS ONLY`（実装）。

### 5.3 マスタ画面の初期化（イベント No5 / No6 / No7）

- **【実測】** `set_reg_sts` は **`MAKER_CD` / `MAKER_NM` / `MAKER_ANM` の 3 つがすべて非空**なら

### 5.7 登録・更新・削除後の共通処理

1. 新規・複製 → INSERT、修正 → UPDATE、削除／削除選択 → `DEL_FLG='1'` の UPDATE。
2. INSERT 時：`DEL_FLG='0'`、`SEND_KBN='0'`、`ASD_STU_FLG='0'`、`REV_NO=開始値`。
3. 削除時：`SEND_STS` は更新前 `'9'` なら維持、それ以外は `'0'`。
4. 緊急配信チェック ON なら
   `R60_EMERGENCY_SEND_CTL_PKG('R60_MAKER_M_TBL', ログインユーザID, 'R60Maker')`。
5. `R60I0001`（登録）／`R60I0002`（削除）を表示し、画面を閉じて一覧を再検索する。
