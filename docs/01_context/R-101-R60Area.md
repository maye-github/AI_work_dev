# R-101 要求背景 - 朝日ビール 調達生産 エリアマスタ（R60Area）

> 本ドキュメントは R-101 の **要求背景（context）** を記録する。ID 及び定義の唯一源は
> `docs/00_registry/ids.yml`（NFR-1 単一ソース）。本ファイルは背景説明のみを担い、
> 画面項目（I-201〜I-256）や設計（D-043）の定義を再記載してはならない。

## 背景 5 条

1. **朝日ビール 調達生産ドメインの共通マスタ** — R60Area は調達生産領域の基幹共通マスタであり、
   拠点（事業場）と在庫の受払・計上ロジックの基準となるエリア情報を一元管理する。

2. **エリアマスタ 56 項目** — 対象テーブルは `R60_AREA_M_TBL`。物理 56 列に対応する画面項目を
   `I-201`〜`I-256`（56 件）として発号済み（`docs/00_registry/ids.yml` 参照）。機能仕様は `F-042`。

3. **三鍵の複合主キー** — レコード一意性は `cmpCd`（会社コード）＋ `jigCd`（事業場コード）＋
   `araCd`（エリアコード）の三鍵で担保する。キー重複時は `E-003`（R60W0014）を返却。

4. **排他制御（ksn_dat + rev_no）** — 更新系（edit / delete）は `ksn_dat`（改竄日時）と
   `rev_no`（リビジョン番号）を比較する楽観ロック方式。不一致時は `E-002`（R60W0006）を返却。
   業務ロジックは `L-015`（initEdit / edit / delete）に集約。

5. **検索ページング（OFFSET-FETCH と ROWID）** — 一覧検索は OFFSET-FETCH 方式を基礎とし、
   必要に応じて ROWID ページングを併用する（`doc/01/OFFSET_FETCH_ROWID` 報告書準拠、rule 5）。
   検索ロジックは `L-014`、検索結果 0 件時は `E-001`（R60W0010）。一覧は **CSV ダウンロード** に対応する。
