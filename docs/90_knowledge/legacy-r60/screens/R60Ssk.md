## 5. 業務処理説明（【文書】`13_業務処理説明` 215 行）

### 5.1 イベント共通

1. **セッション情報存在チェック**：無ければセッション情報エラー画面へ。
2. **オンライン利用可否フラグチェック**：NG ならオンライン制御エラー画面へ。

【実測】コントローラの 5 端点はすべて先頭で `r60util.chk_onl_flg()` を呼ぶ。
セッション確認はフロント／共通基盤側で、コントローラには現れない。

### 5.2 検索（イベント No4）

1. **単項目チェック**（3 項目）

   | 項目 | 条件 | メッセージ |
   |---|---|---|
   | 会社コード | 必須 | R60W0009 |
   | 組織ユニット | 半角英数字以外、または 8 文字超過 | R60W0106 |
   | 正式名称 | 半角英数字以外、または 40byte 超過 | R60W0131 |

2. **WHERE の生成**：会社＝完全一致、組織ユニット＝前方一致、正式名称＝中間一致。
   未入力の項目は条件に加えない。
3. **検索上限件数チェックと 1 頁件数の取得**：標準仕様参照。
   0 件 → R60W0010、上限超過 → R60W0005。
4. **抽出一覧項目**：`R60_GET_SELECT_COLUMN_FNC('R60_SSK_M_TBL', 'L')`。
5. **ソート**：`DEL_FLG` 昇順 → `CMP_CD` 昇順 → `SSK_UNIT` 昇順。
6. **ページング**：1 頁件数で分割し、総件数・総頁数を返す。
7. **ボタン活性**：戻る・ダウンロードは 1 件以上で活性、0 件で非活性。新規は常に非活性。

> **★処理番号が (1)(2)(4)(5)(6)(7)(8)** で、**(3) が欠番**である（D-SS-11）。
> **★R60W0106 の文言は「半角数字」**だが、チェック内容は「半角英数字以外」（D-SS-14）。

### 5.3 一覧リンク → マスタ項目画面（イベント No10）

1. 選択行の `CMP_CD` と `SSK_UNIT` をキーに、**修正モード**で起動する。
2. 経理用会社リストを生成する（会社マスタ、`DEL_FLG='0'`、`CMP_CD` 昇順、先頭ブランク）。
3. 経理用事業場リストを生成する（会社＋事業場、双方 `DEL_FLG='0'`、`HYJ_SEQ NOT NULL`、
   `HYJ_SEQ` → `CMP_CD` → `JIG_CD` 昇順、先頭ブランク）。
4. 登録ボタンは**権限区分:Y** の時のみ活性。
5. 【実測】**削除ボタンは修正モードでも非活性**。設計に活性化条件は無い。

### 5.4 経理用会社変更（イベント No14）

1. 経理用事業場リストを削除する。
2. **経理用会社がブランク以外**：その会社に該当する事業場だけを並べ、空白行を初期値にする。
3. **経理用会社がブランク行**：
   - 選択行の経理事業場に値があり、かつ選択行の会社と経理会社が同じ場合、
     ブランク行と**その経理事業場だけ**のリストを作る。
   - それ以外はブランク行のみ。
4. 【実測】`R60SskEdit.vue:282-310` の `updateJigList` がこの規則を実装している。

> **★設計の前提**：「HR から受信したばかりのデータは経理事業場が未設定」（BP r186）。
> だからブランク行の時に「現在の経理事業場」だけを残す、という例外が必要になる。

### 5.5 登録（イベント No16）

1. **単項目チェック**
   - 全項目に変更なし → R60W0016
   - 経理用会社と経理用事業場の片方だけ → R60W2002
2. **項目間・DB 整合チェック**：`KSN_DAT` を再読込し、他端末更新済みなら R60W0006。
   設計の注記は「バッチの場合は OK」。
3. **登録ステータス設定**：会社・組織ユニット・事業場組織ユニット・正式名称の
   いずれかが未設定なら `'0'`、すべて設定済みなら `'1'`。
4. **UPDATE**：`CMP_CD` と `SSK_UNIT` を条件に、項目移送表の「更新 ○」9 列だけを更新する。
5. **commit** し、マスタ項目画面を閉じて検索結果を最新化する。

| 列 | 設定値 | 出所 |
|---|---|---|
| `S_CMP_CD` / `S_JIG_CD` | 画面の経理用会社・経理用事業場 | BP r211 |
| `REG_STS` | 4 項目判定で `'1'` / `'0'` | BP r206-r208 / 【実測】`set_reg_sts` |
| `SEND_STS` | `'0'`（未送信） | `項目移送表(DB)` r22 |
| `KSN_KBN` | `'1'`（オンライン） | 【実測】 |
| `KSN_STF_ID` | セッションの社員コード | 【実測】 |

| `KSN_PGM_ID` | `'R60Ssk'` | 【実測】 |

> **★設計書の中に、設計自身を否定する実装メモがある。**
