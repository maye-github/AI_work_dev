# 課題：要求書の「暗黙の論点」を読む能力が、本骨架に無い

> **出所**：ユーザーの指摘（2026-10-15）。R60Login の演習中、
> 「人は経験で要求書の含意を読み、確認すべき点を立てる。**AI にその技能が無い。**
> 履歴案件から学ばせて、agent／skill に持たせたい」との指示を受けて起票した。
> **これは「坑」ではなく「能力の欠落」である**（`review_diff_assets` ではなく本ファイルに置く理由）。

## 2. なぜ漏れるか（機構上の原因）

節点1 の作業票（`nodes/n01-requirements.md`）と実行体（`trans-cosmos-ai-node1-requirements`）が
課しているのは次の 1 点だけである：

> **曖昧・矛盾・欠落は消さずに残す。それを見つけて列挙することが本ノードの主目的である。**

しかし実行体の**実際の動作は「入力 → 分類 → 転記」**である。そして——

> **★要求書がよく書けているほど、この動作は「転記」に近づく。**
> 要求書の質を上げると未確定事項は減るが、**それは「論点が無くなった」ことを意味しない。**
> **減ったのは「表面の缺口」であって、「審査すべき論点」は減っていない。**

現在の実行体ができるのは **缺口検出**である。必要なのは **審査**である。
**この 2 つは別の能力であり、片方を強くしても他方は得られない。**
