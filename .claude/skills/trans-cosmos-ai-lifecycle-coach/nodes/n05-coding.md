## 8. よくある失敗と対策

| 症状 | 原因 | 対策 |
|---|---|---|
| 設計に無い処理が入った | AI が「親切に」補った | 削除させ、必要なら**ノード3 へ戻して設計に書く** |
| `R60Common.ts` を書き換えた | 既存関数を「コピーして改変」した | 復元し、**呼び出しのみ**に書き直す（禁①） |
| `src/` や `app/routers` を触った | 出力先の指定が曖昧だった | `tutorial/` 配下へ戻す（Phase 1 制約） |
| SQL を f-string で組み立てた | 値の埋め込み | プレースホルダ束縛に直す。ソート列は白名単経由（規則 03 §5） |
| `trace_check` を `--skip` で通した | 赤线⑥違反 | **やり直し。** `--skip` は記録上も違反として残る |
