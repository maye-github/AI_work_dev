## 1. 背景

弊社は調達・生産系の各種マスタを**新しい基盤で構築**する。
その中で、**メーカー（資材・原材料の供給元）の情報**を維持管理する画面が必要である。

メーカーマスタは、**購入品目別仕入先マスタ**および**原材料仕入単価マスタ**から
**参照される基礎データ**である。したがって、登録・変更・削除を行う際には、
**他のマスタからの参照関係を壊さないこと**が求められる。

本要望書は、その画面「**メーカーマスタメンテナンス（R60Maker）**」の構築をお願いするものである。

## 2. 対象範囲

- **対象**：メーカーマスタメンテナンスの**検索画面**・**マスタ画面**、および**その API**。
- **対象外（明示）**：
  - **購入品目別仕入先マスタ**、**原材料仕入単価マスタ**の各画面そのもの。
    本画面は、それらからの**参照の有無を確認するのみ**である。
  - **緊急配信の配信処理そのもの**。本画面は**弊社の共通部品を呼び出すのみ**である。
  - **メーカー情報の一括取り込み（アップロード）**。本件には含まない。
- **関連する共通部品**：**共通ヘッダ**、**ページャ**、**セッションエラー画面**、
  **オンライン制御エラー画面**、**システムエラー画面**。

### 3.5 検索

**条件の組み合わせ**：入力された条件の **AND** とする。空の条件は**検索条件に含めない**。

| 条件 | 扱い |
|---|---|
| メーカーコード | **前方一致**（入力値で始まるもの） |
| メーカー日本語名 | **中間一致**（入力値を含むもの） |
| 削除含む = オフ | **削除済みのデータを除く** |
| 削除含む = オン | 削除済みのデータも含める |
| 仕掛表示 | **登録が未確定のデータのみ**を対象とする。確定済みは対象外 |

**並び順**

1. **削除済みかどうか**（未削除を先）
2. **メーカーコード**の昇順

利用者が**ソートを指定できるのは「メーカーコード」と「メーカー日本語名」の 2 項目のみ**とする。
それ以外の指定は受け付けず、上記の既定の並び順とする。

**件数**

- **該当 0 件**の場合は、一覧を表示せずメッセージを表示する。
- **上限件数を超えた場合**は、一覧を表示せずメッセージを表示する。**上限値は弊社の共通仕様による**（§3.11）。

**ページング**：1 頁件数は画面で選択した値を用いる。頁の移動は弊社標準規約による（§3.11）。

**ダウンロード**：**直前に実行した検索条件**をそのまま用いて CSV を出力する。
出力項目と並び順は**一覧と同じ**とする。ファイル形式・文字コード・ファイル名の付け方は
**弊社標準規約による**（§3.11）。

### 3.6 マスタ画面の初期化

マスタ画面は**3 つのモード**を持つ。

| モード | 引き継ぐ値 | 初期状態 |
|---|---|---|
| **新規** | なし | 全項目が空。緊急配信はオフ。削除欄はブランク |
| **複製** | **メーカーコード・メーカー日本語名・メーカーカナ名** | 上記 3 項目のみ値を引き継ぐ。**緊急配信はオフ・削除欄はブランク** |
| **修正** | 対象行の**全項目** | 登録されている値をそのまま表示する。**メーカーコードは変更できない** |

**複製の扱い**：複製は**あくまで新規登録の下書き**である。
**緊急配信と削除の状態は引き継がない**（新規と同じ扱い）。

### 3.7 登録・更新

「登録」ボタン押下時の処理を、モードごとに示す。**上から順に確認し、違反した時点で中断する。**

**新規・複製**

| 順 | 確認 | 内容 |
|---|---|---|
| 1 | メーカーコード必須 | 未入力ならエラー |
| 2 | メーカーコード形式 | 半角英数字 5 文字以内でなければエラー |
| 3 | 緊急配信の必須 | 緊急配信がオンのとき、日本語名・カナ名が未入力ならエラー（§3.10） |
| 4 | 名称の形式 | 日本語名・カナ名が §3.9 の条件を満たさなければエラー |
| 5 | 変更なし（**複製のみ**） | 全項目が引き継いだ値のままなら、**登録せずメッセージを表示して終了** |
| 6 | 登録確認 | 利用者に確認を求める。**No なら中断** |
| 7 | **キーの重複** | 同じメーカーコードが既に存在する場合はエラー。**エラー時はメーカーコードを強調表示する** |
| 8 | 登録 | 新規レコードとして登録する |

**修正**

| 順 | 確認 | 内容 |
|---|---|---|
| 1 | 緊急配信の必須 | 緊急配信がオンのとき、日本語名・カナ名が未入力ならエラー |
| 2 | 削除選択の必須 | 削除をオンにして登録するとき、日本語名・カナ名が未入力ならエラー |
| 3 | 名称の形式 | §3.9 の条件を満たさなければエラー |
| 4 | 変更なし | 全項目が変更されていなければ、**登録せずメッセージを表示して終了** |
| 5 | 登録確認 | 利用者に確認を求める。**No なら中断** |
| 6 | **被参照チェック**（**削除をオンにした場合のみ**） | §3.8 と同じ。参照されていれば削除できない |
| 7 | **排他** | 他の利用者が先に更新していた場合はエラーとし、**処理を中断**する |
| 8 | 更新 | 既存レコードを更新する。**削除をオンにした場合は論理削除**とする |

**登録・更新の共通**

- 完了したら**完了メッセージ**を表示し、**マスタ画面を閉じて一覧を再検索**する。
- **緊急配信がオンの場合**は、完了後に**緊急配信の処理を起動**する（§3.10）。

### 3.8 削除

「削除」ボタン押下時の処理。**上から順に確認し、違反した時点で中断する。**

| 順 | 確認 | 内容 |
|---|---|---|
| 1 | **名称の必須** | **緊急配信のオン・オフにかかわらず**、日本語名・カナ名が未入力ならエラー |
| 2 | 名称の形式 | §3.9 の条件を満たさなければエラー |
| 3 | 削除確認 | 利用者に確認を求める。**No なら中断** |
| 4 | **被参照チェック** | **購入品目別仕入先マスタ**または**原材料仕入単価マスタ**から参照されている場合は削除できない |
| 5 | **排他** | 他の利用者が先に更新していた場合はエラーとし、**処理を中断**する |
| 6 | 更新 | **論理削除**とする。**物理削除は行わない** |
| 7 | 緊急配信 | 緊急配信が指示されている場合、緊急配信の処理を起動する（§3.10） |
| 8 | 完了 | 完了メッセージを表示し、マスタ画面を閉じて一覧を再検索する |

**被参照チェックの考え方**：メーカーは**他のマスタの基礎データ**であるため、
**参照されている限り削除させない**。参照の有無は**弊社の共通部品**で判定する（§3.11）。

### 3.9 入力チェック

| 項目 | 必須となる条件 | 桁・文字種 | 使用できない文字 |
|---|---|---|---|
| メーカーコード | **新規・複製**では必須（修正では変更不可） | 半角英数字 **5 文字以内** | なし（文字種の制約のみ） |
| メーカー日本語名 | **緊急配信の指定時**、**削除時**、**削除を選択して登録するとき** | **30Byte 以内**（全角使用可） | カンマ・アポストロフィ・ダブルクォート・パイプ（縦線） |
| メーカーカナ名 | 同上 | **半角カナ 15 文字以内** | アポストロフィ・カンマ・円マーク・半角スペース |

**違反したときの扱い**：**該当項目の背景色を変え、その項目にフォーカスを移す**。
**メッセージの文面は弊社標準規約による**（§3.11）。

**検索条件の入力チェック**：検索画面の「メーカーコード」「メーカー日本語名」も同じ桁・文字種で確認する。
違反した場合は**検索を行わず**、該当項目にフォーカスを移す。

### 3.10 緊急配信

- 「緊急配信」にチェックを付けて登録または削除した場合、**弊社の共通部品による緊急配信の処理を起動**する。
  本画面は**これを呼び出すのみ**であり、配信の仕組みそのものは本件の対象外である。
- **緊急配信を指定するときは、メーカー日本語名とメーカーカナ名の入力が必須**である（§3.9）。
- 一覧には**送信状態**を表示する（§3.2 #16）。

## 5. エラー処理

「正常／業務エラー／システムエラー」を**区別できること**（§3.11 の標準規約による）。

| 事象 | 扱い |
|---|---|
| 検索結果が 0 件 | **業務エラー**。メッセージを表示し、明細を表示しない |
| 検索結果が上限件数を超えた | **業務エラー**。メッセージを表示し、明細を表示しない |
| メーカーコードが既に存在する（新規・複製） | **業務エラー**。メーカーコードを強調表示する |
| 他のマスタから参照されている（削除） | **業務エラー**。削除しない |
| 他の利用者が先に更新していた（排他） | **業務エラー**。処理を中断する |
| 被参照チェックの共通部品が想定外の結果を返した | **システムエラー**。処理を中断する |
| 入力チェック違反（画面側） | 該当項目を強調表示し、フォーカスを移す。**サーバへは送らない** |
| セッション情報が存在しない | **セッションエラー画面へ遷移**する |
| オンライン利用が許可されていない | **オンライン制御エラー画面へ遷移**する |
| **API の権限検証で権限が不足している** | **業務エラー**。処理を中断する。**画面のボタン活性制御は補助であり、これとは独立に判定する**（§3.1） |
| DB エラー・想定外の例外 | **ロールバック**し、**システムエラー画面へ遷移**する |

## 7. 用語

| 用語 | 含义 |
|---|---|
| メーカー | 資材・原材料の供給元となる会社 |
| マスタ | 主データ（master data）。業務の基础となる一覧データ |
| 仕掛 | 登録が**未確定**の状態。確定前のデータを指す |
| 確定 | 登録内容が確定し、他のマスタから参照できる状態 |
| 緊急配信 | 登録・削除の内容を、関連する仕組みへ**即時に通知**する処理 |
| 送信状態 | 緊急配信の送信状況（未送信／送信済みなど） |
| 削除（論理削除） | レコードを消さずに「削除済み」の印を付けること |
| 排他 | 複数の利用者が同時に更新した場合に、後からの更新を防ぐこと |
| 被参照 | 他のマスタから参照されていること |
| 削除含む | 削除済みのデータも検索対象に含めるかどうかの指定 |
