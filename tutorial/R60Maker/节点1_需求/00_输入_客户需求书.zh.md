## 1. 背景

本公司正以**新基盘**构建采购・生产系的各类主数据。
其中需要**维护厂商（资材・原材料的供应方）信息**的画面。

厂商主数据是被**按采购品目区分的供应商主数据**以及**原材料采购单价主数据**
**所参照的基础数据**。因此，登记・变更・删除时，
**不得破坏其他主数据的参照关系**。

本需求书即是对该画面「**厂商主数据维护（R60Maker）**」的委托。

## 2. 对象范围

- **对象**：厂商主数据维护的**检索画面**・**主数据画面**，以及**其 API**。
- **对象外（明示）**：
  - **按采购品目区分的供应商主数据**、**原材料采购单价主数据**各自的画面本身。
    本画面**只做参照有无的确认**。
  - **紧急配信（紧急下发）的处理本身**。本画面**只调用本公司的共通部品**。
  - **厂商信息的一次性导入（上传）**（即"导入"）。本件不含。
- **相关共通部品**：**共通页眉**、**分页器**、**会话错误画面**、
  **在线控制错误画面**、**系统错误画面**。

### 3.5 检索

**条件组合**：已输入条件之间为 **AND**。空条件**不纳入检索条件**。

| 条件 | 处理 |
|---|---|
| メーカーコード | **前方一致**（以输入值开头者） |
| メーカー日本語名 | **中间一致**（含输入值者） |
| 削除含む = 关 | **排除已删除的数据** |
| 削除含む = 开 | 已删除的数据也包含在内 |
| 仕掛表示 | **仅以登记未确定的数据**为对象。已确定者不在对象内 |

**排序**

1. **是否已删除**（未删除在前）
2. **メーカーコード** 升序

用户**可指定排序的仅「メーカーコード」与「メーカー日本語名」2 项**。
其他指定一律不接受，按上述既定顺序排列。

**件数**

- **命中 0 件**时，不显示一览，显示消息。
- **超过上限件数**时，不显示一览，显示消息。**上限值依本公司共通规格**（§3.11）。

**分页**：每页件数采用画面选定的值。页的移动依本公司标准规约（§3.11）。

**下载**：**直接采用上一次执行的检索条件**输出 CSV。
输出项目与排序**与一览相同**。文件格式・字符编码・文件命名方式
**依本公司标准规约**（§3.11）。

### 3.6 主数据画面的初始化

主数据画面有**3 种模式**。

| 模式 | 继承的值 | 初始状态 |
|---|---|---|
| **新建** | 无 | 全项目为空。紧急配信为关。删除栏为空白 |
| **复制** | **メーカーコード・メーカー日本語名・メーカーカナ名** | 仅继承上述 3 项。**紧急配信为关・删除栏为空白** |
| **修正** | 对象行的**全部项目** | 原样显示已登记的值。**メーカーコード不可修改** |

**复制的处理**：复制**只是新建登记的草稿**。
**不继承紧急配信与删除的状态**（与新建相同处理）。

### 3.7 登记・更新

按下「登録」按钮时的处理，按模式示明。**自上而下依次确认，违反即中断。**

**新建・复制**

| 顺序 | 确认 | 内容 |
|---|---|---|
| 1 | メーカーコード必填 | 未输入则报错 |
| 2 | メーカーコード格式 | 非半角英数字 5 位以内则报错 |
| 3 | 紧急配信的必填 | 紧急配信为开时，若日本語名・カナ名未输入则报错（§3.10） |
| 4 | 名称的格式 | 日本語名・カナ名不满足 §3.9 条件则报错 |
| 5 | 无变更（**仅复制**） | 全部项目仍为继承值则**不登记**，显示消息并结束 |
| 6 | 登记确认 | 向用户确认。**选 No 则中断** |
| 7 | **键重复** | 同一メーカーコード已存在则报错。**报错时高亮メーカーコード** |
| 8 | 登记 | 作为新记录登记 |

**修正**

| 顺序 | 确认 | 内容 |
|---|---|---|
| 1 | 紧急配信的必填 | 紧急配信为开时，若日本語名・カナ名未输入则报错 |
| 2 | 删除选择的必填 | 打开删除后登记时，若日本語名・カナ名未输入则报错 |
| 3 | 名称的格式 | 不满足 §3.9 条件则报错 |
| 4 | 无变更 | 全部项目均未变更则**不登记**，显示消息并结束 |
| 5 | 登记确认 | 向用户确认。**选 No 则中断** |
| 6 | **被参照检查**（**仅在打开删除时**） | 与 §3.8 相同。被参照则不可删除 |
| 7 | **排他** | 其他用户已先行更新时视为错误，**中断处理** |
| 8 | 更新 | 更新已存在的记录。**打开删除时按逻辑删除**处理 |

**登记・更新的共通处理**

- 完成后显示**完成消息**，**关闭主数据画面并重新检索一览**。
- **紧急配信为开时**，完成后**启动紧急配信处理**（§3.10）。

---

### 3.8 删除

按下「削除」按钮时的处理。**自上而下依次确认，违反即中断。**

| 顺序 | 确认 | 内容 |
|---|---|---|
| 1 | **名称必填** | **无论紧急配信开或关**，若日本語名・カナ名未输入则报错 |
| 2 | 名称的格式 | 不满足 §3.9 条件则报错 |
| 3 | 删除确认 | 向用户确认。**选 No 则中断** |
| 4 | **被参照检查** | 若被**按采购品目区分的供应商主数据**或**原材料采购单价主数据**参照，则不可删除 |
| 5 | **排他** | 其他用户已先行更新时视为错误，**中断处理** |
| 6 | 更新 | 按**逻辑删除**处理。**不做物理删除** |
| 7 | 紧急配信 | 指定了紧急配信时，启动紧急配信处理（§3.10） |
| 8 | 完成 | 显示完成消息，关闭主数据画面并重新检索一览 |

**被参照检查的思路**：厂商是**其他主数据的基础数据**，因此
**只要被参照就不允许删除**。参照有无由**本公司的共通部品**判定（§3.11）。

---

### 3.9 输入检查

| 项目 | 必填的条件 | 位数・字符种 | 不可使用的字符 |
|---|---|---|---|
| メーカーコード | **新建・复制**时必填（修正时不可修改） | 半角英数字 **5 位以内** | 无（仅约束字符种） |
| メーカー日本語名 | **指定紧急配信时**、**删除时**、**打开删除后登记时** | **30Byte 以内**（可用全角） | 逗号・撇号・双引号・竖线（`|`） |
| メーカーカナ名 | 同上 | **半角片假名 15 位以内** | 撇号・逗号・日元符号・半角空格 |

**违反时的处理**：**改变该项目的背景色，并将焦点移到该项目**。
**消息文面依本公司标准规约**（§3.11）。

**检索条件的输入检查**：检索画面的「メーカーコード」「メーカー日本語名」也按相同位数・字符种确认。
违反时**不执行检索**，将焦点移到该项目。

### 3.10 紧急配信

- 勾选「緊急配信」后登记或删除时，**启动由本公司共通部品执行的紧急配信处理**。
  本画面**仅调用**该部品，配信机制本身不在本件对象内。
- **指定紧急配信时，メーカー日本語名与メーカーカナ名必须有输入**（§3.9）。
- 一览中显示**发送状态**（§3.2 #16）。

以下**依本公司的标准**，本需求书不个别规定。

- **错误响应・消息・日志的格式**依本公司的**标准规约**。
  「正常／业务错误／系统错误」的区分以及**错误码体系**也依标准规约的方式（§5）。
- **共通页眉**、**分页器**、**会话错误画面**、**在线控制错误画面**、
  **系统错误画面**是本公司的**共通部品**。本件**调用它们**，
  **不在本件中新建**。
- **代码值的名称**（发送状态・删除区分等）从本公司的**代码值主数据**取得。
  本画面**仅取得并显示**。
- **登记状态（仕掛／确定）的判定基准**依**本公司的共通规格**。
  本画面**仅使用其判定结果**。
- **审计项目**（登记人・登记时间・更新人・更新时间・修订号等）的赋予
  依**本公司的共通规格**。本画面不个别决定这些值。
- **被参照检查**由本公司的**共通部品**判定。
- **每页件数的候选**、**检索的上限件数**依本公司的**共通规格**。
- **非功能**（支持浏览器・画面分辨率・并发用户数・性能）**依本公司的标准**。
- **会话的有效期限・超时时的处理**依**本公司的共通规格**。
  本画面**不新生成会话**。

## 4. 接口（API）

**6 个端点**。**全部为 POST**。路径为 `/R60Maker/<name>`。
请求为 `{"params": {...}}` 的形式，响应的项目名为**驼峰式**。

### 4.1 一览

| # | 端点 | 对应事件 | 职责 |
|---|---|---|---|
| 1 | `POST /R60Maker/init` | 事件 1 | 返回初始显示所需信息（每页件数候选・消息） |
| 2 | `POST /R60Maker/search` | 事件 2・3 | 返回符合条件的明细与总件数 |
| 3 | `POST /R60Maker/download` | 事件 8 | 按上一次执行的条件返回 CSV |
| 4 | `POST /R60Maker/initEdit` | 事件 5・6・7 | 按模式返回主数据画面的初始值 |
| 5 | `POST /R60Maker/delete` | 事件 11 | 执行逻辑删除 |
| 6 | `POST /R60Maker/edit` | 事件 12 | 执行新建・复制・更新 |

> **事件 4・9・10・13 没有端点。** 属于画面内处理，或依本公司标准规约的跳转。

### 4.2 `POST /R60Maker/init`

| | |

## 5. 错误处理

「正常／业务错误／系统错误」**必须可区分**（依 §3.11 的标准规约）。

| 事象 | 处理 |
|---|---|
| 检索结果为 0 件 | **业务错误**。显示消息，不显示明细 |
| 检索结果超过上限件数 | **业务错误**。显示消息，不显示明细 |
| メーカーコード 已存在（新建・复制） | **业务错误**。高亮 メーカーコード |
| 被其他主数据参照（删除） | **业务错误**。不删除 |
| 其他用户已先行更新（排他） | **业务错误**。中断处理 |
| 被参照检查的共通部品返回预期外结果 | **系统错误**。中断处理 |
| 输入检查违反（画面侧） | 高亮该项目并将焦点移入。**不发送到服务器** |
| 会话信息不存在 | **转向会话错误画面** |
| 不允许在线使用 | **转向在线控制错误画面** |
| **API 的权限验证中权限不足** | **业务错误**。中断处理。**画面的按钮活性控制只是辅助，与此独立判定**（§3.1） |
| DB 错误・预期外的异常 | **回滚**，并**转向系统错误画面** |

## 7. 用语

| 用语 | 含义 |
|---|---|
| メーカー | 提供资材・原材料的厂商 |
| マスタ | 主数据（master data）。业务基础所需的清单数据 |
| 仕掛 | 登记**未确定**的状态。指确定前的数据 |
| 确定 | 登记内容已确定、可被其他主数据参照的状态 |
| 緊急配信 | 将登记・删除的内容**即时通知**到相关机制的処理 |
| 送信状态 | 紧急配信的发送情况（未发送／已发送等） |
| 删除（逻辑删除） | 不删除记录，只加"已删除"标记 |
| 排他 | 多名用户同时更新时，防止后到的更新覆盖 |
| 被参照 | 被其他主数据参照 |
| 削除含む | 是否把已删除的数据也纳入检索对象的指定 |
