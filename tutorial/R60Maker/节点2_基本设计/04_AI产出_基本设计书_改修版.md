## 2. 画面遷移図

```text
前画面 → 検索画面（SCR-201） → マスタ画面（SCR-202）
              ↑                      │
              └── 戻る／登録・削除完了 ──┘
```

| 起点 | 操作 | 遷移先 | 条件 |
|---|---|---|---|
| 前画面 | 検索画面を開く | 検索画面 | 利用権限保持者 |
| 検索画面 | 新規 | マスタ画面（新規モード） | 検索成功後（0 件も検索成功として扱う） |
| 検索画面 | 複製 | マスタ画面（複製モード） | 検索成功後、かつ行が選択されていること |
| 検索画面 | 一覧セルのメーカーコード／日本語名を押下 | マスタ画面（修正モード） | 検索成功後 |
| マスタ画面 | 登録・削除の完了 | 検索画面 | 完了メッセージ後、最後に実行した検索条件で再検索（1 頁目） |
| マスタ画面 | 戻る | 検索画面 | 確認（MSG-C-003）で承認した場合 |
| 検索画面 | 戻る | 前画面 | 検索成功後 |
| 検索画面 | 業務終了 | 業務終了 | 確認（MSG-C-004）で承認した場合 |
| 任意 | セッション無効の応答 | セッションエラー画面 | `errorCode="9"` かつ `errorId="9001"` |
| 任意 | オンライン利用不可の応答 | オンライン制御エラー画面 | `errorCode="9"` かつ `errorId="9002"` |
| 任意 | システムエラーの応答 | システムエラー画面 | `errorCode="9"` かつ上記以外 |
