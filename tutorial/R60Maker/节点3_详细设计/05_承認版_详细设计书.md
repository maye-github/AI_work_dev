### 2.0 端点と経路（**2026-11-10 追加・CR-006**）

**経路は要求 §6 が唯一の出所である。** 旧版はここを書いておらず、実装が
「ルート直下（`/init`）＋ 前端が `/api` を前置」という第三の解釈を採っていた。
要求・設計・実装で 3 つ違っていたため、本節で確定する。

| # | 端点 | メソッド | **パス** | 主ロジック | 要求本文 |
|---|---|---|---|---|---|
| 1 | 初期表示 | POST | `/R60Maker/init` | L-212 → L-213 | 受ける |
| 2 | 検索 | POST | `/R60Maker/search` | L-212 → L-214 → L-215 | 受ける |
| 3 | ダウンロード | POST | `/R60Maker/download` | L-212 → L-218 | **受けない**（最後の検索条件のみ） |

| 5 | 削除 | POST | `/R60Maker/delete` | L-212 → L-219 | 受ける |
| 6 | 登録更新 | POST | `/R60Maker/edit` | L-212 → L-220 | 受ける |

- **前置き（`/api` 等）をコードに埋めない。** デプロイ時のリバースプロキシ接頭辞は環境設定であり、
  アプリは `/R60Maker/<name>` で受ける。前端も同じパスを呼ぶ。
- 前端から見た基底は環境設定 1 箇所に集約する（散らかさない）。
- `X-Session-Id` は**共通部品が注入する**（要求 §8 #9。本画面は自前で作らない）。
  注入されない構成では、セッション系（E-221）は未観測であると記録する。

### 4.3 検索処理（L-214）総件数の取得

```sql
-- 条件は一覧取得と同一。空条件はアプリ側で除外する。
SELECT COUNT(*)
  FROM MKR_TBL
 WHERE (maker_cd LIKE :maker_cd_prefix OR :maker_cd_prefix IS NULL)
   AND (maker_nm LIKE :maker_nm_partial OR :maker_nm_partial IS NULL)
   AND (del_flg = :not_deleted OR :include_deleted = :include_deleted_val)
   AND (reg_kbn = :shikake_kbn OR :shikake_mode = :shikake_off)
```

### 4.4 検索処理（L-214）一覧の取得

```sql
-- ソート白名单（識別子は値ではないため :BIND 不可。白名单で担保する）:
--   ALLOWED_SORT_FIELDS = {MAKER_CD, MAKER_NM}
--   白名单外・未指定は固定ソート ORDER BY del_flg, maker_cd, 行識別子 へフォールバック。
--   白名单指定時も第 1 キーは del_flg（未削除を先）を維持する。
-- 任意頁への直接移動（頁番号 1 始まり）のため OFFSET/FETCH を例外採用する。
--   安定順序のため末尾に物理行識別子（例: ROWID。工程04 で確定）を付す。
SELECT maker_cd, maker_nm, maker_kana_nm, send_sts, del_flg
  FROM MKR_TBL
 WHERE (maker_cd LIKE :maker_cd_prefix OR :maker_cd_prefix IS NULL)
   AND (maker_nm LIKE :maker_nm_partial OR :maker_nm_partial IS NULL)
   AND (del_flg = :not_deleted OR :include_deleted = :include_deleted_val)
   AND (reg_kbn = :shikake_kbn OR :shikake_mode = :shikake_off)
 ORDER BY del_flg, maker_cd, ROWID
 OFFSET :offset ROWS FETCH NEXT :page_size ROWS ONLY
```

### 4.5 ダウンロード処理（L-218）一覧の取得

```sql
-- 最後に実行した検索条件で抽出する。件数 500 超は E-214 で出力しない。
-- 列は一覧 5 列。CSV は UTF-8（BOM あり）・CRLF・ヘッダ行あり。
SELECT maker_cd, maker_nm, maker_kana_nm, send_sts, del_flg
  FROM MKR_TBL
 WHERE (maker_cd LIKE :maker_cd_prefix OR :maker_cd_prefix IS NULL)
   AND (maker_nm LIKE :maker_nm_partial OR :maker_nm_partial IS NULL)
   AND (del_flg = :not_deleted OR :include_deleted = :include_deleted_val)
   AND (reg_kbn = :shikake_kbn OR :shikake_mode = :shikake_off)

```

### 4.7 削除処理（L-219）論理削除

```sql

-- 排他: last_update_datetime と rev_no の両方の一致を要する（E-217）。

   SET del_flg = :deleted,
       last_update_datetime = :new_last_update_datetime,
       rev_no = rev_no + 1,
       upd_user = :upd_user
 WHERE maker_cd = :maker_cd
   AND last_update_datetime = :last_update_datetime
   AND rev_no = :rev_no
```
