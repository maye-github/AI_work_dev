## 4. SQL 模板

> **以下为方言无关的逻辑 SQL。** 物理方言、执行计划、分页实现将在工程04 技术选型批准后确定（红线④）。
> **表名、列名为 AI 草案（等待 Q-308b），不是确定值。**
> 所有值均以 `:BIND` 形式的占位符（例：`:maker_cd`）接收，不嵌入实际值、实际代码、实际数据。

### 4.1 前処理（L-212）权限代码取得

```sql

SELECT auth_cd
  FROM AUTH_TBL
 WHERE user_id = :user_id
```

### 4.2 初期化処理（L-213）消息信息取得

```sql

  FROM MSG_TBL

```

### 4.3 検索処理（L-214）总件数取得

```sql
-- 条件与列表取得相同。空条件由应用侧排除。
SELECT COUNT(*)
  FROM MKR_TBL
 WHERE (maker_cd LIKE :maker_cd_prefix OR :maker_cd_prefix IS NULL)
   AND (maker_nm LIKE :maker_nm_partial OR :maker_nm_partial IS NULL)
   AND (del_flg = :not_deleted OR :include_deleted = :include_deleted_val)
   AND (reg_kbn = :shikake_kbn OR :shikake_mode = :shikake_off)
```

### 4.4 検索処理（L-214）列表取得

```sql
-- 排序白名单（标识符不是值，不能 :BIND。由白名单保证）:
--   ALLOWED_SORT_FIELDS = {MAKER_CD, MAKER_NM}
--   白名单外、未指定时回退到固定排序 ORDER BY del_flg, maker_cd, 行标识符。
--   指定白名单时也保持第 1 键为 del_flg（未删除在前）。
-- 为支持任意页直接移动（页号 1 起始），例外采用 OFFSET/FETCH。
--   为保证稳定顺序，末尾附加物理行标识符（例：ROWID。工程04 确定）。
SELECT maker_cd, maker_nm, maker_kana_nm, send_sts, del_flg
  FROM MKR_TBL
 WHERE (maker_cd LIKE :maker_cd_prefix OR :maker_cd_prefix IS NULL)
   AND (maker_nm LIKE :maker_nm_partial OR :maker_nm_partial IS NULL)
   AND (del_flg = :not_deleted OR :include_deleted = :include_deleted_val)
   AND (reg_kbn = :shikake_kbn OR :shikake_mode = :shikake_off)
 ORDER BY del_flg, maker_cd, ROWID
 OFFSET :offset ROWS FETCH NEXT :page_size ROWS ONLY
```

SELECT maker_cd, maker_nm, maker_kana_nm, send_sts, del_flg

| E-223 | DB 错误、预期外异常 | 9 | 9999 | — | 回滚，替换为 SystemErrorScreen | 错误日志 |
| E-224 | 服务器侧输入检查违反（与画面侧相同条件） | 1 | 2005 | MSG-E-007／MSG-E-008 | 显示消息，中断处理（不迁移画面） | 操作日志 |

- **响应共通规则**：HTTP 状态全部为 200，判定以正文 errorCode 为准。errorCode 为 0=正常／1=业务错误／9=系统错误（不使用 2）。errorId 为 4 位（正常时 0000）。
- **画面迁移主体**：errorCode=9 时替换为错误画面。errorCode=1 时不迁移画面。
- **写入日志的值**：敏感值（连接信息、密钥、实际数据）不写入操作日志。遮蔽委托共通日志部件，本画面不自行输出。
