5.2 SQL-1 运行判定（L-201）

-- 运行判定。调用方: /init・/login・/generateUrl 的开头（3 个端点全部）。
-- 0 件・无效值・例外一律视为「不可运行」（E-203 / E-206）。
SELECT operation_flg
  FROM SYS_CMN_TBL
 WHERE cmn_key = :operation_key;
  • :operation_key — 定位运行标志行的共通键。键值由环境配置给出（裁决 Q-234。设计里不写实际值）。

5.3 SQL-2 画面候选的取得（L-202）

-- 画面候选。仅有效行・按显示顺序升序。全公司共通（不按使用者过滤）。
SELECT gmn_id,
       gmn_nm
  FROM GMN_MST
 WHERE valid_flg = :valid
 ORDER BY disp_order, gmn_id;
  • :valid — 有效标志的「有效」值为 1（裁决 Q-234）。

       o.cmp_cd,
