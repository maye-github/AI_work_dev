## D-201　ユーザーＩＤの桁数: 「7 桁固定」と「最大 7 桁」の矛盾

| 項目 | 内容 |
|---|---|
| 事象 | 要求書は **半角 7 桁**と明記しているが、承認版の Q-210 裁定は **「半角数字・最大 7 桁（7 桁固定ではない）」** としている |
| 出所（要求書） | `tutorial/R60Login/节点1_需求/00_输入_客户需求书.md:61`「**半角 7 桁**」／`:101`「**必須**かつ**半角 7 桁**」 |

| 原因 | Q-210 の裁定が、要求書の明文（7 桁）を上限の記述と読み替えた。**裁定が要求書に優先した** |
| 修正案 | Q-210 の裁定を **「半角数字 7 桁固定・必須」** に訂正する。文字種（数字のみ）と trim／全角除去は C（当方の正規化）のまま |

## D-202　システム日時の表示形式: `hh` と `HH`（24 時間制）の矛盾

| 項目 | 内容 |
|---|---|
| 事象 | 要求書は **`YYYY/MM/DD hh:mm:ss`** と書くが、承認版の Q-218 裁定は **`HH`（24 時間制）** としている |
| 出所（要求書） | `00_输入_客户需求书.md:60`「弊社標準規約による（§3.8）。**`YYYY/MM/DD hh:mm:ss`** 形式」 |
| 出所（承認版） | `04_承認版_需求结构化表.md:136`（`hh`）／`:536`（Q-218 裁定は `HH`・24 時間制） |
| 影響 | 表示仕様が 12 時間制か 24 時間制かで変わる。ただし 12 時間制には AM/PM 表記が無く、そのままでは運用できない |
| 原因 | 要求書は書式を **顧客標準規約（§3.8）に委ねている**が、同規約は未提供（§12 #1）。当方が C として 24 時間制を決めた |
| 修正案 | 二段に分ける。**A**: 顧客標準規約（§3.8）の提供を求める（書式の権威は顧客）。**B**: 規約が無い場合の当方提案として `YYYY/MM/DD HH:mm:ss`・24 時間制を提示し承認を得る。**Q-218 を C 単独で確定させない** |

## D-203　暗号化算式の 2 つの境界規則が要求に無い（実装にしか無い）

| 項目 | 内容 |
|---|---|
| 事象 | Q-201 の回答は算式の**骨格**（各桁 +1／先頭桁はゼロ埋めなし・2 桁目以降は 2 桁ゼロ埋め／4 桁超は分割／各ブロックに当日 `yyyymmdd` を加算／`_` で連結）を写しているが、**2 つの境界規則**を欠く。①**`9` は常に `10` になる**（1 桁に切り詰めない・次桁へ桁上げしない）。②**ブロック分割の境界は 5 桁目**（前ブロックは常に 4 桁）。 |
| 出所（要求側） | `tutorial/R60Login/节点1_需求/04_承認版_需求结构化表.md` §11.2 Q-201（v1.0.2）。`00_输入_客户需求书.md` §4.5 は「暗号化して送信する」までで、算式そのものを書いていない |
| 出所（実測） | 歴史資産カード `legacy-r60/screens/R60Login.md` §12.2 【未確認】1（同カード自身が「設計書からは復元できない」と記録している）。**本記録では実装の式そのものを写さない**（対比報告 `comparison.md` 節点2 §改善提案 3 と同じ扱い） |
| 影響 | **節点 3 で詳細設計を起こした時点で分岐が確定する。** 現状の文言のままだと `9` を `0`＋桁上げと読む実装が起こり得て、その場合は**旧システムと非互換**になる。発覚するのは結合テスト（A/B 比較）であり、その時点の手戻りは詳細設計・製造・単体テストの 3 工程に及ぶ |
| 原因 | **要求の書き漏れではなく、要求の「深さ」の不足**。Q-201 は「方式の互換性」を A として顧客に返したが、返ってきた回答が骨格までで止まっていた。**境界規則は「値」ではなく「値に付いた例外と形」**であり、移送検査（`rules/02` §9）の 4 種のうち「限定句」「形状」に当たる |
| 修正案（案） | Q-201 の回答に**2 条件を追記**する。区分は **A のまま**（既存互換仕様は顧客しか持っていない）。演習では仮想答案として補い、**実案件では顧客の設計書または回答で確定させる**。Q-201 の回答文を書き換えるか、**Q-227 として独立に立てるかは人が決める** |

## 記録の位置づけ

- 本ファイルは**測定記録ではなく作業記録**である。訓練の事後対比（`comparison.md`）は書き換えない。
